# Legacy OSINT monolith

This directory holds the pre-MVP Informed News stack (React/Supabase/Express OSINT app, Vercel API, docs, and scheduled workflows).

It is **not** the primary application. Do not wire it into `mvp/`.

To explore historically:

```bash
cd _legacy/backend && npm install && npm run dev
# separately: legacy Vite app under _legacy (see former root package.json history)
```

Primary app: `../mvp/`
